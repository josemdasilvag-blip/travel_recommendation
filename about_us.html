About this demo

Wanderlynx Travel is a fictional travel brand created for a JavaScript course project. It is a front-end demonstration, not a travel agency. It does not sell trips, hold a travel agency licence, or accept bookings.

What you can try

Search for beach, temple or country, or type a destination name. The site reads a local JSON file, shows matching recommendations and calculates local time using each destination's time zone.

The destination list is sample content for the exercise. Search results are for exploration, not personalized travel advice.
